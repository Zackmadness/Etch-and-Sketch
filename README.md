# 🎨 Etch-and-Sketch

A browser-based drawing application inspired by the classic Etch-A-Sketch toy, built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.


## 📖 Overview

This project is an interactive sketching application that allows users to draw by hovering over a customizable grid. It was created to practice JavaScript DOM manipulation, event handling, dynamic element creation, and responsive layout techniques.

## ✨ Features

- 🖌️ **Interactive Drawing** – Draw by simply moving the cursor over the grid.
- 📐 **Custom Grid Sizes** – Create grids ranging from 1×1 up to 100×100 squares.
- 🔄 **Dynamic Grid Generation** – Entire grid is created and recreated using JavaScript.
- 📱 **Responsive Layout** – Fixed drawing area that adapts while maintaining square proportions.
- 🧹 **Reset Functionality** – Quickly clear and regenerate the drawing board.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Zackmadness/Etch-and-Sketch.git
```

### Navigate to the Project Directory

```bash
cd Etch-and-Sketch
```

### Run the Project

Open `index.html` in your preferred web browser.
